# clipfmt コマンド設計書

## 概要

クリップボード上のMarkdownを整形（format）して書き戻す `tools clipfmt` サブコマンド。

解決したい問題:

- 手打ちしたMarkdownの表の桁が揃っておらず読みにくい
- 箇条書きの記号が `-` / `*` / `+` で混在している
- 見出しが `===` 形式（Setext）と `#` 形式（ATX）で混在している
- 番号付きリストの番号が `1. 1. 1.` や `3. 7.` のように不揃い
- 余分な空行や行末の空白が散らばっている

サブコマンド名・単体エントリーポイント名ともに `clipfmt`
（`pyproject.toml` の `[project.scripts]` に `clipfmt = "tools.cli:run_as_subcommand"` を追加）。

## 入出力

- 入力: クリップボードの `CF_UNICODETEXT`（Markdownテキスト）
- 出力: 整形後のMarkdownを `CF_UNICODETEXT` に書き戻す（`CF_HTML` はセットしない）
- ファイルは作らない

`CF_HTML` があってもそれは無視し、常に `CF_UNICODETEXT` をMarkdownとして扱う
（整形はMarkdownテキストに対する操作であり、リッチテキストは対象外）。

`CF_UNICODETEXT` が無い場合はエラー終了する。

## 整形の実装

### ライブラリ

**`mdformat` + `mdformat-tables`** を使う（`markdown-it-py` と同系列のCommonMark準拠フォーマッタ）。

依存追加: `mdformat`, `mdformat-tables`。`clipfmt` 実行時のみ使うため**遅延インポート**にする。

呼び出しは `mdformat.text(src, extensions={"tables"})`。
`extensions={"tables"}` を渡さないと表が整形されないため必須（検証済み）。

### mdformat が行うこと（検証済み）

| 項目 | 挙動 |
|---|---|
| 表の桁揃え | **日本語の全角幅も考慮して列幅を揃える**。`---:` の右寄せも保持される |
| 見出しの統一 | Setext形式（`見出し\n====`）を ATX形式（`# 見出し`）に変換 |
| 番号付きリスト | 番号を `1.` に統一（`3.` `7.` の不揃いが直る） |
| 行末空白 | 除去される |
| 連続する空行 | 1行に圧縮される |

### 前処理: 箇条書き記号の統一

**mdformat 単体では、記号混在の箇条書きが意図せず分断される**（検証済み）。

CommonMarkでは箇条書きの記号が変わると**別のリスト**として解釈される。
そのため `*` / `+` / `-` が混在した入力に mdformat をかけると、
隣接する別リストを区別するために記号が交互になり、間に空行が挿入される。

```text
入力:                    mdformatのみ:
*   箇条書きA            - 箇条書きA
+ 箇条書きB       →      （空行）
-   箇条書きC            * 箇条書きB     ← 記号が変わる
                         （空行）
                         - 箇条書きC
```

これはCommonMark仕様上は正しいが、**手打ちで記号が混ざっただけのケースでは
利用者の意図（1つのリストにまとめたい）と食い違う**。

そこで **mdformat にかける前に、行頭の箇条書き記号 `*` / `+` を `-` に統一する前処理**を入れる。

```text
前処理後:                最終結果:
-   箇条書きA            - 箇条書きA
- 箇条書きB       →      - 箇条書きB
-   箇条書きC            - 箇条書きC
```

#### 前処理で触ってはいけない範囲

前処理は正規表現による行単位の置換になるため、**Markdownとして記号の意味を持たない箇所を
書き換えないよう保護する**必要がある。

- **コードフェンス（```` ``` ```` / `~~~`）の内側は一切触らない**
  （コード中の `+ x` や `* y` を箇条書きと誤認しないため。検証で保護できることを確認済み）
- 引用（`>`）の内側にある箇条書きは統一の対象とする
  （引用内でも箇条書きであることに変わりはない。検証済み）
- インデントされた箇条書き（ネスト）も対象とする

対象とする行の判定は「行頭（空白と `>` の並びを除いて）が `*` または `+` で、
その直後に空白が続く行」とする。`**太字**` の行頭出現などを誤って書き換えないよう、
**記号の直後に空白があることを条件に含める**。

## オプション

| オプション | 既定 | 内容 |
|---|---|---|
| `--no-normalize-bullets` | 無効（=統一する） | 箇条書き記号の統一前処理を行わない。CommonMarkの解釈をそのまま尊重したい場合に使う |

整形は「いつも同じ結果になる」ことに価値があるため、細かい整形規則のオプションは設けない
（`mdformat` の既定に従う）。

## ログ

- 整形前後で内容が変わったかどうかをログに出す
  （変わらなかった場合は「既に整形済み」と分かるようにする）
- 箇条書き記号の統一を行った場合はその旨をログに出す
  （記号が変わったことに利用者が気づけるようにする）

## エラー処理

- `CF_UNICODETEXT` が無い場合: 「整形対象のテキストがありません」と明示してエラー終了
- 整形結果が空文字列になった場合: エラー終了する
  （空をクリップボードに書き込むと元の内容を失うだけで害しかない）
- `mdformat` が入力をパースできずに例外を投げた場合:
  **クリップボードを書き換えずに**、その旨を明示してエラー終了する
  （壊れた結果で元の内容を上書きしない。整形前の内容が失われないことを優先する）

## セキュリティ方針との整合（CLAUDE.md）

- クリップボードの読み書きは `win32clipboard` の公開APIのみ。実行時に1回だけ読み書きする
- 外部通信は発生しない（整形はすべてローカル処理）
- ファイルの作成・削除は行わない
- 何をしたか（整形の有無、記号統一の有無）をログに出す

## 他コマンドとの関係

| コマンド | 役割 |
|---|---|
| `clipmd` | Markdown ↔ リッチテキスト ↔ TSV の**形式変換** |
| `clipview` | Markdown/HTML を**ブラウザで表示** |
| `clipfmt` | Markdown を**整形**（形式は変えない） |

`clipmd` の TSV → Markdownの表 変換は桁揃えを行わない。
桁を揃えたい場合は `clipmd` の後に `clipfmt` を続けて実行する運用とする
（コマンドを1つに詰め込まず、責務を分けたまま組み合わせられるようにする）。

## テスト方針

`tests/processing/test_clipfmt.py` に以下を用意する。
クリップボードAPIは `monkeypatch` でモックする。

### 整形内容

- 表の桁が揃うこと（**日本語を含む表で全角幅が考慮されること**）
- 表の列の配置指定 `---:` が保持されること
- `extensions={"tables"}` を渡さないと表が整形されないことの退行検知
  （実装が誤ってプラグインを外した場合に気づけるようにする）
- Setext形式の見出しがATX形式（`#`）になること
- 番号付きリストの番号が `1.` に統一されること
- 行末の空白が除去されること
- 連続する空行が圧縮されること

### 箇条書き記号の統一（前処理）

- `*` / `+` / `-` 混在の箇条書きが、**1つのリストにまとまること**
  （間に空行が挿入されないこと、記号が交互にならないこと）
- **コードフェンス内の `+ x` / `* y` が書き換えられないこと**
- 引用（`>`）内の箇条書きが統一されること
- ネストされた箇条書きが統一されること
- 行頭の `**太字**` が箇条書きと誤認されて書き換えられないこと
- `--no-normalize-bullets` 指定時に前処理が行われないこと

### 入出力

- 整形結果が `CF_UNICODETEXT` に書き戻されること
- `CF_HTML` がセットされないこと
- `CF_HTML` があっても無視して `CF_UNICODETEXT` を整形対象にすること

### ログ

- 整形により内容が変わった場合にその旨がログに出ること
- 内容が変わらなかった場合に「整形済み」と分かるログが出ること
- 箇条書き記号を統一した場合にログが出ること

### エラー

- `CF_UNICODETEXT` が無い場合にエラー終了すること
- 整形結果が空になる場合にエラー終了すること
- **`mdformat` が例外を投げた場合、クリップボードが書き換えられないこと**
