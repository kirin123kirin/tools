画像処理

touka

単体実行: touka.exe

画像の背景を透過する（ファイルパス／クリップボード入力対応）

usage: touka [-h] [-o OUTPUT] [path]

画像の背景を透過する（ファイルパス／クリップボード入力対応）

positional arguments:
  path                  画像ファイルパス。省略時はクリップボードの画像/コピーしたファイルを使用

options:
  -h, --help            show this help message and exit
  -o OUTPUT, --output OUTPUT
                        出力先パス（省略時は自動生成、拡張子はpng）

denoise

単体実行: denoise.exe

画像のノイズ除去（ファイルパス／クリップボード入力対応、OpenCV Non-local Means）

usage: denoise [-h] [-o OUTPUT] [--strength STRENGTH] [path]

画像のノイズ除去（ファイルパス／クリップボード入力対応、OpenCV Non-local Means）

positional arguments:
  path                  画像ファイルパス。省略時はクリップボードの画像/コピーしたファイルを使用

options:
  -h, --help            show this help message and exit
  -o OUTPUT, --output OUTPUT
                        出力先パス（省略時は自動生成、拡張子はpng）
  --strength STRENGTH   ノイズ除去強度 h（デフォルト: 10.0）。値を大きくするほどノイズは減るがディテールも失われる

kukiri

単体実行: kukiri.exe

JPEGの輪郭滲みを除去し境界をくっきりさせる（フラットイラスト向け）

usage: kukiri [-h] [-o OUTPUT] [--smooth SMOOTH] [--sharpen SHARPEN] [path]

JPEGの輪郭滲みを除去し境界をくっきりさせる（フラットイラスト向け）

positional arguments:
  path                  画像ファイルパス。省略時はクリップボードの画像/コピーしたファイルを使用

options:
  -h, --help            show this help message and exit
  -o OUTPUT, --output OUTPUT
                        出力先パス（省略時は自動生成、拡張子はpng）
  --smooth SMOOTH       バイラテラルフィルタの強さ（デフォルト: 75.0）。大きいほど滲みは消えるが細部も失われる
  --sharpen SHARPEN     アンシャープマスクの強さ（デフォルト: 0.5、0で無効）。大きいほど境界のコントラストが強調される

テキスト集計

cwc

単体実行: cwc.exe

テキストからワードクラウド画像を生成する（ファイルパス／クリップボード入力対応）

usage: cwc [-h] [-o OUTPUT] [--encoding ENCODING] [-w]
           [--hinshi HINSHI [HINSHI ...]] [--semantic]
           [--synonym-dict SYNONYM_DICT] [--no-synonym-dict]
           [--user-dict USER_DICT] [--no-user-dict] [--stopwords STOPWORDS]
           [--stopwords-file STOPWORDS_FILE] [--no-default-stopwords]
           [--font FONT] [--similar] [--similar-threshold SIMILAR_THRESHOLD]
           [--similar-model SIMILAR_MODEL]
           [--similar-max-length SIMILAR_MAX_LENGTH]
           [path]

テキストからワードクラウド画像を生成する（ファイルパス／クリップボード入力対応）

positional arguments:
  path                  テキストファイルパス。省略時はクリップボードのテキスト/コピーしたファイルを使用

options:
  -h, --help            show this help message and exit
  -o OUTPUT, --output OUTPUT
                        出力先パス（省略時は自動生成、拡張子はpng）
  --encoding ENCODING   入力ファイルのエンコーディングを明示指定（省略時はUTF-8→CP932の順に試す）
  -w, --wakachi         Janomeによる分かち書きで分割する
  --hinshi HINSHI [HINSHI ...]
                        集計対象の品詞を指定（複数可、カンマ区切りも可）。指定可能: 名詞, 動詞, 形容詞, 副詞, 助詞,
                        助動詞, 連体詞, 接続詞, 感動詞, 接頭詞, 記号, フィラー, その他
  --semantic            同義語辞書で異表記を代表語に寄せる
  --synonym-dict SYNONYM_DICT
                        同義語辞書ファイルのパス
  --no-synonym-dict     同義語辞書を一切使用しない
  --user-dict USER_DICT
                        Janomeユーザー辞書のパス
  --no-user-dict        Janomeユーザー辞書を一切使用しない
  --stopwords STOPWORDS
                        追加するストップワード（カンマ区切り）
  --stopwords-file STOPWORDS_FILE
                        追加するストップワードのファイルパス
  --no-default-stopwords
                        デフォルトのストップワードを無効化する
  --font FONT           使用するフォントファイルのパス
  --similar             集計単位を語ではなく文にし、埋め込みベクトルの類似度でクラスタリングする
  --similar-threshold SIMILAR_THRESHOLD
                        --similar のクラスタをまとめる距離の閾値（コサイン距離、既定: 0.2）
  --similar-model SIMILAR_MODEL
                        --similar で使用する埋め込みモデル名
  --similar-max-length SIMILAR_MAX_LENGTH
                        --similar の代表文の表示文字数の上限（0で無制限、既定: 10）

表形式データ

profiler

単体実行: profiler.exe

表形式データの各列をプロファイルする（欠損・一意性・頻度上位・主キー候補）

usage: profiler [-h] [-o OUTPUT] [--clip] [--view] [--sep SEP]
                [--header HEADER] [--no-header] [--top TOP]
                [--empty-values EMPTY_VALUES] [--no-default-empty-values]
                [path ...]

表形式データの各列をプロファイルする（欠損・一意性・頻度上位・主キー候補）

positional arguments:
  path                  対象ファイル（複数・グロブ可）。省略時はクリップボードのTSVを読む

options:
  -h, --help            show this help message and exit
  -o OUTPUT, --output OUTPUT
                        出力先パス（.tsv / .xlsx）
  --clip                結果をクリップボードにコピーする
  --view                結果をブラウザでHTML表示する
  --sep SEP             区切り文字（拡張子判定を上書き）
  --header HEADER       ヘッダー行のインデックス（0始まり、既定0）
  --no-header           ヘッダーなしとして扱う
  --top TOP             頻度上位の表示件数（既定10、0で非表示）
  --empty-values EMPTY_VALUES
                        空とみなす値のカンマ区切りリスト（既定値を置き換える）
  --no-default-empty-values
                        既定の空値リストを無効化し、Noneと空文字だけを空とみなす

lsdir

単体実行: lsdir.exe

フォルダ配下をExcelで集計できる表形式で一覧化する

usage: lsdir [-h] [-o OUTPUT] [--clip] [--files-only] [--dirs-only]
             [--exclude EXCLUDE [EXCLUDE ...]] [--include-temp] [--total-size]
             [--unit {b,kb,mb,gb}] [--resolve-link] [--encoding ENCODING]
             path [path ...]

フォルダ配下をExcelで集計できる表形式で一覧化する

positional arguments:
  path                  対象フォルダ（複数・グロブ可）

options:
  -h, --help            show this help message and exit
  -o OUTPUT, --output OUTPUT
                        出力先パス（.tsv / .xlsx）
  --clip                結果をクリップボードにコピーする
  --files-only          ファイルのみ出力する
  --dirs-only           フォルダのみ出力する
  --exclude EXCLUDE [EXCLUDE ...]
                        除外するフォルダ名（既定: ['.git', '.svn', 'node_modules',
                        '__pycache__']）
  --include-temp        '~$'で始まる一時ファイルも含める
  --total-size          フォルダ配下の合計サイズを計算する（全走査後に出力するため待ち時間が発生する）
  --unit {b,kb,mb,gb}   サイズの単位（既定: kb）
  --resolve-link        .lnkのリンク先を解決する（WScript.Shell経由、大量にあると遅くなる）
  --encoding ENCODING   出力エンコーディング
