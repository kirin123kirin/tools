# tsunagu コマンド設計書

## 概要

PowerPointのコネクタとシェイプの接続を自動化する `tools tsunagu`
サブコマンド。「繋ぎ」から。

解決したい問題:

- コネクタをシェイプに接続する操作は、マウスでコネクタの端点をつまんで
  シェイプの接続点（●印）にぴったり合わせる必要があり、細かく煩わしい。
  少しでもずれると「接続されていない、ただ近くにあるだけの線」になり、
  シェイプを動かしたときに追従しない
- 既に引いてあるコネクタの両端を、近くのシェイプへ一括で吸着させたい。
  あるいは、繋ぎたい2つのシェイプを選ぶだけでコネクタを自動生成したい

サブコマンド名・単体エントリーポイント名ともに `tsunagu`
（`pyproject.toml` の `[project.scripts]` に
`tsunagu = "workpytools.cli:run_as_subcommand"` を追加）。
短く叩きやすい名前を優先している（`vv`/`ikko`/`seiretsu`/`iro`と同じ流儀）。

## 動作の自動判定

`tbl`と同じく、**選択状態から何をするかを自動判定する**。

| 選択内容 | 動作 |
| --- | --- |
| コネクタを1つ以上含み、シェイプも2つ以上含む | **吸着**: 選択中の各コネクタの両端を、選択中のシェイプの最寄り接続点へ接続する |
| コネクタを含まず、シェイプがちょうど2つ | **新規作成**: 2つのシェイプを繋ぐ直線コネクタを新しく作る |
| 上記以外 | エラー終了（後述） |

コネクタかどうかは`Shape.Connector`（`msoTrue`/`msoFalse`）で判定する
（`Shape.Type`が`msoLine`でも、`Connector`が偽なら単なる直線であり
接続はできないため、`Connector`プロパティで判定する必要がある）。

## 対象範囲

- **選択中のシェイプ・コネクタのみ**を対象にする
- **吸着先の候補シェイプも「選択に含まれるシェイプ」に限定する。**
  アクティブスライド上の全シェイプを候補にはしない（意図しない遠くの
  シェイプに吸着してしまう事故を防ぐため、繋ぎたいシェイプは明示的に
  選択してもらう方針とする）
- 選択にコネクタが含まれる場合、**コネクタ以外のシェイプが2つ未満なら
  エラー終了**する（接続先が足りないため）
- 選択にコネクタが含まれない場合、**シェイプがちょうど2つでなければ
  エラー終了**する（どれとどれを繋ぐか自動推測しないため）

## 接続点の選び方

PowerPointのシェイプは形状ごとに接続点（connection site）を持ち、
`Shape.ConnectionSiteCount` で個数を、コネクタ側の
`ConnectorFormat.BeginConnect(shape, site_index)` /
`EndConnect(shape, site_index)` で接続先とサイト番号を指定する
（サイト番号は1始まり）。

**コネクタの端点座標から物理的に一番近い接続点を選ぶ。**

```text
for 各コネクタの端点(始点・終点):
    for 候補シェイプ in 選択中のシェイプ:
        for site_index in 1..shape.ConnectionSiteCount:
            距離 = ユークリッド距離(端点座標, 接続点の座標)
    最短距離の (shape, site_index) を選ぶ
```

- ユーザーがマウスで引いた位置の意図（「この辺に繋ぎたい」）を
  そのまま尊重できるため、2つのシェイプの位置関係から機械的に面を
  決める方式ではなく、端点からの距離で選ぶ
- **始点と終点で同じシェイプが選ばれた場合はエラー**とする
  （自分自身に繋がる不正な接続を防ぐ。「一番近いシェイプ」が両端で
  同じになるのは、コネクタが1つのシェイプの近くに孤立して置かれている
  ような、意図が読めない状況のため）

### 接続点の座標をどう取得するか

PowerPoint COMには「シェイプのN番目の接続点の座標」を直接返すプロパティが
**存在しない**。そのため、シェイプの外接矩形（`Left`/`Top`/`Width`/`Height`）
から接続点の座標を計算する。

`ConnectionSiteCount`が4の場合（四角形・角丸四角形など大半の基本図形）、
PowerPointの接続点は**上・左・下・右の順**に1〜4が割り当てられる。

```text
site 1: (Left + Width/2, Top)             上辺の中央
site 2: (Left,           Top + Height/2)  左辺の中央
site 3: (Left + Width/2, Top + Height)    下辺の中央
site 4: (Left + Width,   Top + Height/2)  右辺の中央
```

`ConnectionSiteCount`が4以外のシェイプ（円・三角形・フローチャート記号
など、形状ごとに接続点数が異なる）については、**外接矩形の周囲を
site数で等分した点で近似する**。

```text
site i (1始まり) の角度 = -90度 + 360度 * (i-1) / site_count
    （上辺中央を起点に時計回り、という PowerPoint の一般的な並びに合わせる）
座標 = 外接矩形の中心 + (cos(角度) * Width/2, sin(角度) * Height/2)
```

この近似は厳密には実際の接続点位置と一致しない場合があるが、
**「複数ある接続点のうちどれが一番近いか」を選ぶ用途では十分**である
（隣接する接続点との距離差は通常シェイプサイズの半分程度あり、
近似誤差がその差を覆すことは少ない）。厳密な座標が必要な場面では
ないため、この割り切りを設計として明記する。

## 吸着（既存コネクタの再接続）

選択中の各コネクタについて、以下を行う。

1. コネクタの現在の始点座標・終点座標を取得する
   （`Left`/`Top`/`Width`/`Height`から、線の向き
   `ConnectorFormat`の`BeginConnected`等ではなく、単純に矩形の
   対角として計算する。既存の接続の有無に関わらず、**現在画面上で
   見えている端点位置**を基準にしたいため）
2. 始点に最も近い接続点を持つシェイプを選ぶ
3. 終点に最も近い接続点を持つシェイプを選ぶ
4. 始点・終点で同じシェイプが選ばれたらエラー終了
5. `connector.ConnectorFormat.BeginConnect(始点シェイプ, サイト番号)`
   `connector.ConnectorFormat.EndConnect(終点シェイプ, サイト番号)`
   を呼んで接続する

### 既に接続済みのコネクタ

既に何かに接続されているコネクタも、**現在の見た目の端点位置を基準に
再計算して繋ぎ直す**（`BeginDisconnect`/`EndDisconnect`は呼ばず、
`BeginConnect`/`EndConnect`で上書きする。PowerPointの仕様上、
接続済みのコネクタに対して再度`BeginConnect`を呼んでも問題なく
繋ぎ先が切り替わる）。

## 新規作成（シェイプ2つ選択時）

選択されたシェイプがちょうど2つで、コネクタが含まれない場合。

1. 2つのシェイプの**中心座標同士**を比べ、互いに最も近い接続点の
   組み合わせを選ぶ（両シェイプの全接続点の組み合わせについて距離を
   計算し、最短の組を選ぶ）
2. `slide.Shapes.AddConnector(msoConnectorStraight, 0, 0, 0, 0)` で
   直線コネクタを作成する（座標は仮の値。この後の`BeginConnect`/
   `EndConnect`で自動的に正しい位置へ移動する）
3. `BeginConnect`/`EndConnect`で1で選んだ接続点へ接続する
4. 線の色を黒、太さを2ptに設定する（`iro`コマンドで定めた既定書式に
   合わせる。矢印は付けない）

- 選択順序（どちらが始点か）は`ShapeRange.Item(1)`を始点、`Item(2)`を
  終点とする

## 変更しないもの

- シェイプの位置・サイズ・形状・書式・テキスト
- コネクタの線種・色・太さ（**新規作成時のみ**黒・2ptを設定する。
  既存コネクタの吸着では線の見た目を一切変更しない）
- シェイプの個数（吸着モードでは新規作成も削除もしない）

## エラー処理

- PowerPointが起動していない場合: 「PowerPointでプレゼンテーションを
  開いた状態で実行してください」と表示してエラー終了する（新規起動はしない）
- プレゼンテーションが開かれていない場合: 同様にエラー終了する
- 何も選択されていない場合: 「コネクタとシェイプ、または繋ぎたい
  シェイプを2つ選択してから実行してください」と表示してエラー終了する
- コネクタを含むが、シェイプが2つ未満の場合: 「接続先のシェイプを
  2つ以上選択してください」と表示してエラー終了する
- コネクタを含まず、シェイプが2つでない場合: 「繋ぎたいシェイプを
  ちょうど2つ選択してください（コネクタを選択すればその両端を
  吸着させます）」と表示してエラー終了する
- 始点・終点で同じシェイプが選ばれた場合: 「コネクタの両端が同じ
  シェイプに最も近いため、接続先を判断できません」と表示して
  エラー終了する
- COM操作中に例外が発生した場合: 例外内容を含めたエラーメッセージで終了する。
  `Application.StartNewUndoEntry()`により、Ctrl+Z一回で開始前の状態に
  戻せる旨をメッセージに含める

## 元に戻す（Undo）

`ikko`・`tbl`・`seiretsu`・`nagasa`・`iro`と同じ理由で、**処理を開始する
直前に`Application.StartNewUndoEntry()`を必ず呼ぶ。** 境界を打たないと
1回のCtrl+Zがどこまで巻き戻るか制御できない。

## 出力・ログ

処理内容を`common/logging.py`経由でログに出す。

- 実行したモード（吸着 / 新規作成）
- 吸着したコネクタの本数、または新規作成したコネクタの本数
- 各コネクタがどのシェイプのどのサイト番号に接続されたか（デバッグ用）

完了時に標準出力へ1行のサマリを表示する
（例: `2本のコネクタを最寄りのシェイプに接続しました` /
`1本のコネクタを作成して接続しました`）。

## セキュリティ方針との整合（CLAUDE.md）

- **COM操作は`pywin32`の公開APIのみ**を使う。生のWindowsフック・
  メモリ改ざん・プロセスインジェクションは行わない
- キー入力の自動送信・グローバルキーフックは行わない
  （マウス操作の代替であっても、マウス/キー入力のシミュレーションは
  一切行わず、COMのオブジェクトモデル経由でのみ接続を設定する）
- **常駐・バックグラウンド監視をしない。** 実行のたびに1回だけ
  対象を読んで接続し、終了する
- **外部通信は発生しない**（すべてローカルのPowerPointへのCOM操作のみ）
- 何本のコネクタをどのシェイプに繋いだかを`common/logging.py`経由で
  ログに出す

## 他コマンドとの関係

- `seiretsu`（シェイプを格子状に整列）・`nagasa`（サイズ統一）で
  レイアウトを整えた後、`tsunagu`でコネクタを繋ぐ、という流れを想定
- 新規作成時の線の書式（黒・2pt）は`iro`コマンドで定めた矢印の既定書式に
  合わせている

## テスト方針

接続点の座標計算・最寄り接続点の選択ロジックは、COM非依存の純粋関数として
`common/connector_sites.py`に切り出し、`tests/common/`でテストする。
`tests/processing/test_tsunagu.py`ではPowerPoint COMオブジェクトを
`MagicMock`でモックする。

### 接続点の座標計算（純粋関数）

- `ConnectionSiteCount`が4のとき、上・左・下・右の順に正しい座標が返ること
- `ConnectionSiteCount`が4以外（例: 8）のとき、外接矩形の周囲を等分した
  座標が返ること
- 幅と高さが異なるシェイプでも、楕円状に正しく分布すること

### 最寄り接続点の選択（純粋関数）

- 複数シェイプ・複数接続点の中から、指定座標に最も近い
  (シェイプ, サイト番号) の組が選ばれること
- 距離が同じ候補が複数ある場合、決定的な順序（最初に見つかったもの）で
  選ばれること

### 動作の自動判定

- コネクタ1本＋シェイプ2つの選択で、吸着モードになること
- コネクタなし・シェイプちょうど2つの選択で、新規作成モードになること
- コネクタを含むがシェイプが1つしかない場合、エラー終了すること
- コネクタなし・シェイプが3つ以上の場合、エラー終了すること
- 何も選択していない場合、エラー終了すること

### 吸着

- **コネクタの両端がそれぞれ最寄りのシェイプ・サイト番号へ
  `BeginConnect`/`EndConnect`されること**
- 複数のコネクタが選択されている場合、全てのコネクタが処理されること
- 始点・終点で同じシェイプが選ばれた場合、エラー終了し、
  `BeginConnect`が一切呼ばれないこと
- 既に接続済みのコネクタでも、現在の端点位置を基準に繋ぎ直されること
- **コネクタの線の色・太さが変更されないこと**（吸着モードでは
  見た目を変えない）

### 新規作成

- `AddConnector`が`msoConnectorStraight`で呼ばれること
- 作成されたコネクタが両シェイプへ`BeginConnect`/`EndConnect`
  されること
- 線の色が黒、太さが2ptに設定されること
- 選択順（`Item(1)`が始点、`Item(2)`が終点）が守られること

### `StartNewUndoEntry`

- **処理開始前に`StartNewUndoEntry()`が呼ばれること**
  （他のPowerPoint操作コマンドと同じ理由の退行検知）

### エラー処理

- PowerPointが起動していない場合、新規起動を試みずエラー終了すること
- プレゼンテーションが開かれていない場合にエラー終了すること
- COM例外時に、Ctrl+Zで戻せる旨を含むエラーメッセージが出ること
